# AI Prompts & Conversations Log

## Overview
As mandated by the course evaluation criteria, this directory contains the complete, unsummarized record of all interactions, prompts, queries, and assistant responses generated during the design, implementation, testing, and presentation of the **Network Telemetry Framework** project.

## Files Included
1. **[`raw_conversations.md`](./raw_conversations.md)**:
   - Complete chronological verbatim transcript in human-readable Markdown format.
   - Contains all 26 interaction turns, with exact user prompts and unedited assistant responses.
   - No summaries or abridgments; includes tool and test execution audit traces.

2. **[`prompts_and_responses.json`](./prompts_and_responses.json)**:
   - Structured JSON dump containing prompt timestamps, user inputs, tool actions, and raw assistant message payloads.

3. **[`raw_transcript_full.jsonl`](./raw_transcript_full.jsonl)**:
   - Exact system-generated JSON Lines transcript file containing full cryptographic step indexes, tokens, timestamps, and execution logs.

## Academic Integrity Confirmation
All AI assistance utilized in this project was strictly for debugging, documentation structuring, test generation, and slide authoring under the supervision and direction of Team T018 members.
