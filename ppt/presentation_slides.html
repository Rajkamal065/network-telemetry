Project Description
This project builds a standardized, high-performance network telemetry framework based on RFC 9232. It replaces slow, pull-based polling with real-time push streaming via gRPC, transporting bandwidth utilization, TCP connection latency, and interface metrics from edge devices directly to a central monitoring backend.
Expected Outcomes
  • Real-Time Monitoring: Live dashboards showing live bandwidth utilization and latency trends across devices with 2-second updates.
  • Threshold-Based Alerting: Instant detection of link saturation (>80%) and latency spikes (>50ms) with anti-flapping hysteresis.
  • Historical Access & Export: Queryable metric storage via REST APIs and one-click CSV export for offline analysis.
  • Scalable Push Telemetry: Asynchronous ingestion handling concurrent data streams without telemetry loss.
Deliverables

Working telemetry pipeline with edge streaming agents, central ingestion engine, alert state machine, live web dashboard, and automated test suite.

Tools & Technologies

gRPC & Protocol Buffers (proto3 HTTP/2 streaming), Python 3.12, FastAPI, SQLite3 (WAL mode + async batch queue), psutil (OS interface counters), Vanilla JS & HTML5 Canvas, Pytest (automated test suite).

UI & Implementation Highlights
Friendly & Professional User Interface
  • Clean Light Theme Dashboard: Enterprise styling with Plus Jakarta Sans typography, subtle shadows, and status badges.
  • Live Device Cards & Utilization Bars: Real-time bandwidth usage with animated visual gauges and sub-0.1% dynamic precision.
  • Canvas Trend Charts: Hardware-accelerated HTML5 canvas line graphs for bandwidth, latency, and throughput without bloated charting libraries.
  • One-Click CSV Export: Immediate CSV download of historical metrics for audit reporting.
Hybrid Telemetry Collection
  • Real Host Probing: Tracks active laptop interface throughput via psutil and measured millisecond TCP connect time to DNS.
  • Realistic Topology Models: Evaluates mathematical traffic curves (sine load + M/M/1 queuing delays) across routers and switches.
Automated Testing & Reliability
  • 30 Automated Pytest Tests: 100% test pass rate covering Protobuf validation, database batching, alert transitions, and REST endpoints.
  • Anti-Flapping Hysteresis Engine: Solves alert fatigue by strictly requiring 2 consecutive breach cycles before alerting and 3 healthy cycles to resolve.
  • Decoupled Asynchronous Buffer: Producer-consumer queue prevents gRPC ingestion lag during disk write spikes.
  • Congestion & Fault Injection: Live simulation tests dynamic 95% traffic saturation and automatic 10-second agent silence offline alerts.

Non-Functional Testing & Results
Performance

Low-latency edge-to-dashboard processing. Compact Protobuf payload consumes ~72 bytes per message (vs ~228 bytes JSON), reducing telemetry transport overhead by ~68%.

Reliability & Fallbacks

Asynchronous queue buffer (20,000 capacity) combined with SQLite WAL mode prevents lock contention. Heartbeat tracking detects and flags disconnected devices within 10 seconds.

Scalability & Modularity

Stateless gRPC streaming architecture easily scales to multiple nodes. The framework accommodates both synthetic mathematical agents and real physical NIC probes seamlessly.

Project Scope & Viva Defense

Implemented as a clean educational prototype of RFC 9232 push telemetry. Uses gRPC streaming rather than legacy SNMP polling; future roadmap includes gNMI and mTLS encryption.
